# Body Parts Working Function Website

An interactive educational website that explains how different human body parts work. Built with HTML, CSS, and JavaScript, this project presents anatomical information in an engaging, visual format with interactive demonstrations.


## Features

- **6 Essential Body Parts** - Detailed cards for brain, heart, lungs, stomach, kidneys, and liver
- **Working Mechanisms** - Clear explanations of how each organ functions
- **Fun Facts** - Interesting trivia about each body part
- **Interactive Demos**:
  - Heart rate simulator (adjustable BPM slider)
  - Lung inflation visualization
  - Muscle function explanation
- **Responsive Design** - Works on desktop and mobile devices
- **Modern UI** - Clean, medical-themed interface with smooth animations

## Body Parts Covered

| Organ | Key Function | Working Detail |
|-------|--------------|----------------|
| Brain | Control centre | 86 billion neurons, 70,000 thoughts/day |
| Heart | Blood pump | 4 chambers, 100,000 beats/day |
| Lungs | Gas exchange | 600 million alveoli, 70m² surface |
| Stomach | Digestion | HCl acid + enzymes, self-protecting mucus |
| Kidneys | Blood filtration | 1 million nephrons, 120-150 quarts/day |
| Liver | Metabolism | 500+ functions, regenerative capacity |

## Customization

### Adding a New Body Part
1. Copy an existing `.card` div
2. Update the icon, title, and text content
3. Maintain the same structure for consistency

### Modifying Content
Edit the text within these sections:
- `.function-text` - Main function description
- `.working-detail` - Detailed mechanism
- `.fun-fact` - Interesting trivia

### Changing Colors
Modify the CSS variables in the `style` section:
- Main teal: `#1a7f7c`, `#116466`, `#328f8c`
- Background gradient: `#e9f2f5` to `#dae5ec`

## Responsive Design

The website is fully responsive:
- **Desktop**: 3-column grid for cards
- **Tablet**: 2-column grid
- **Mobile**: 1-column stacked layout
